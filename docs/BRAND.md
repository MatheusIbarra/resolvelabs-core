# ResolveLabs — identidade visual

**Símbolo:** frasco de laboratório (Labs) com líquido e bolhas, sobre um quadrado arredondado verde-azulado.
**Nome:** `Resolve` em grafite + `Labs` em verde-azulado, fonte Geist Bold.

## Cores
| Uso | Cor |
|---|---|
| Marca (fundo do símbolo, "Labs") | `#0F766E` (teal-700) |
| Líquido / destaque | `#14B8A6` (teal-500) |
| "Labs" sobre fundo escuro | `#2DD4BF` (teal-400) |
| Texto escuro | `#1C1917` (stone-900) |
| Fundo claro | `#FAFAF9` (stone-50) |

## Arquivos
| Arquivo | Para quê |
|---|---|
| `public/brand/mark.svg` | Símbolo colorido (avatar, app) |
| `public/brand/mark-mono-dark.svg` / `mark-mono-light.svg` | Uma cor só (carimbos, impressão, fundos coloridos) |
| `public/brand/logo-horizontal.svg` / `logo-horizontal-dark.svg` | Símbolo + nome (fundo claro / escuro) |
| `public/brand/png/` | Versões raster com fundo transparente (logo @4x, símbolo 512 px) |
| `public/favicon.ico`, `public/icon.svg` | Favicon do navegador |
| `public/apple-touch-icon.png` | Ícone do iOS (180 px) |
| `public/icon-192.png`, `public/icon-512.png`, `public/icon-maskable-512.png` | Ícones do app instalável (PWA) |
| `public/og-image.png` | Imagem de compartilhamento (1200×630) |

## Regras
- Área de respiro mínima: metade da largura do frasco ao redor do símbolo.
- Tamanho mínimo: 16 px (símbolo) e 96 px de largura (logo horizontal).
- Não alongar, girar, trocar as cores nem aplicar sombras ou efeitos.
- Os SVGs com texto usam a fonte Geist (com Inter/Arial como alternativa). Para impressão com fonte garantida, use os PNGs.
